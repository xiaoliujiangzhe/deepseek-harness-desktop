# 启动页三方向设计规格

这是 DeepSeek Harness 社区桌面端的启动窗口方向探索。目标受众既包括熟悉命令行的 DSH 用户，也包括只希望双击桌面图标即可开始使用的普通 Windows 用户。启动窗口是应用每次运行时的第一触点，它首先要让用户确认自己打开的是 DeepSeek Harness，其次要清楚表达本地服务正在启动，最后才承担作者署名和视觉记忆。画面不得像营销落地页，也不能像通用 AI 工具模板；所有元素都要服务于“品牌识别、启动反馈、故障恢复”三件事。

三个方向统一使用 `480×340` 固定画布，与当前 Electron 无边框启动窗口一致。共同内容为官方 vendored Harness 源码中的鲸鱼标识、产品名 `DeepSeek Harness`、属性 `Desktop`、真实启动文案“正在启动本地服务”、进度数值 `64%`、阶段说明“正在确认 HTTP 可访问”以及作者落款 `XLJZ`。方向稿展示正常启动状态；正式实现还必须保留当前错误标题、可复制错误详情、“选择工作目录”和“重试”操作。所有正文不小于 12px，状态信息不小于 14px，文本与背景满足清晰可读；百分比使用等宽数字，动态内容不得引起布局位移。

方向 A 以官方白底和 DeepSeek Blue 为核心，追求安静、精确和可信，视觉母题是“一条正在建立的连接”。方向 B 使用全幅品牌蓝与深色分区，强调鲸鱼进入深水后的空间感，视觉母题是“从深海浮出并建立服务”；它应该有电影感但不能滑向通用霓虹科技风。方向 C 借鉴工程启动清单和工作台标签，使用冷白纸面、规则线和清晰编号，视觉母题是“由 XLJZ 组装并启动的一台可靠工具”；它更个人、更像独立开发者作品，但不能粗糙。

Logo 是内容必需素材，三个方向共用同一份官方 SVG，不使用 CSS 或手绘 SVG 替代。`XLJZ` 必须像作者签名，但占比克制：可以是手写落款、印章或构建标记，不能比产品名更突出。三个方向的布局骨架必须真正不同，不能只是换色。最终用户选定方向后，再制作正式动画节奏、错误态、Windows 多尺寸 ICO、PNG 主图标和托盘图标；正式图标优先使用单独鲸鱼标识，不使用包含文字的横向 wordmark，以保证 16px 到 256px 都能辨识。
