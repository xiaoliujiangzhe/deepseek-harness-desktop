# DeepSeek Harness Desktop 0.5.0

发布日期：2026-08-25

## 本次更新

- 新增右侧内置文件编辑器：点击聊天中的常见文本或代码文件，不再默认跳到记事本或 IDE。
- 支持从桌面工具栏主动选择当前工作区内的文件。
- 支持多文件标签、行号、文件内查找、自动换行、`Ctrl+S`、磁盘重载和外部编辑器备用入口。
- 保存前检测文件是否被其他程序修改，发生冲突时不会静默覆盖。
- 关闭未保存标签或退出应用时给出明确提醒。

## 安全与兼容

- 只能读取和保存当前工作区内的真实文件路径，拒绝目录穿越和指向工作区外的符号链接。
- 疑似二进制内容、超过 2 MB 的文件和不支持的编码不会进入内置编辑器，可由用户确认后改用系统编辑器。
- 保存采用同目录临时文件原子替换，并保留 UTF-8 / UTF-16 BOM 与 LF / CRLF 格式。
- HTML 文件继续使用已有的本地实时预览，不作为文本文件打开。
- Harness 仍固定为 `0.1.1-rc.2`，用户的 `.dsh`、会话、附件、凭据和插件数据不会进入安装包。
