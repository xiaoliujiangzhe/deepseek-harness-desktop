# DeepSeek Harness Desktop 0.4.0（整合说明）

> 此文件保留早期开发记录。由于 `0.5.0` 尚未上传 GitHub，相关功能已合并回当前待发布的 `0.4.0`。

## 本次更新

- 新增独立诊断与修复中心，可检查桌面 Node、Harness、pnpm、工作区、DSH 数据目录、凭据配置、Web profile、本地服务、代理和公共网络端点。
- 支持导出脱敏诊断报告、备份已知运行配置、安全修复 `.credentials.yaml` 的 version 类型，以及清理插件目录缓存。
- 浏览器地址栏支持普通关键词搜索；新增书签、最近访问、移除书签和清除历史。
- 插件中心支持启用、停用和按原来源检查更新，插件依赖在停用时不会被卸载。
- 插件变更继续备份 Web profile，并统一在操作后提示重启桌面端。

## 安全边界

- 诊断不会读取或展示凭据值；导出报告会再次遮蔽 API Key、Bearer Token、密码和常见 secret 字段。
- 凭据修复只处理能够安全确认的非字符串 version，并在写入前创建原文件备份。
- 书签与历史仅保存在 Electron `userData/settings.json`，最多保存 100 个书签和 200 条去重历史；内部主页和 localhost 临时预览不会加入恢复标签。
- 插件更新继续拒绝需要执行第三方生命周期脚本或缺少可验证成品入口的 GitHub 源码。
